# Adding a new vendor risk

**NOTE:** This page has instructions for adding a new **vendor risk** to a project. To add a project risk instead, see[ Adding a new project risk](adding-a-new-project-risk.md).

Vendor risks are risks associated with vendors that provide any third-party component in your AI applications or systems.

&#x20;While you cannot fully control or mitigate vendor risks, any developer or provider of an AI application under the jurisdiction of the _EU AI Act_ still needs to monitor possible vendor risks and prepare for them.

<figure><img src="../../.gitbook/assets/image (6).png" alt=""><figcaption><p>"Add a new vendor risk" window</p></figcaption></figure>

To add a new vendor risk:

1. **Vendor name:** Choose the vendor that is the source of the new vendor risk.
2. **Action owner:** Select the person responsible for monitoring this vendor risk.
3. **Risk name:** Choose a name for the risk.
4. **Review date:** Note the date when the vendor risk in question was last reviewed.
5. **Risk description:** Provide a description of the vendor risk.
6. Click `Save` to create the new vendor risk.
